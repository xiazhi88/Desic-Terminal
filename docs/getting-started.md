## 1. Desic Terminal 是什么

Desic Terminal 是一个 **AI 原生的 OKX USDT 永续合约交易终端**，把六个工作域整合在同一个实时上下文里：

| 工作域 | 你能做什么 |
| --- | --- |
| **交易工作站** | 行情、盘口、深度、K 线、下单、持仓管理 |
| **专业图表** | 多周期多窗格图表、20+ 内置指标、图层、绘图与图表快速交易 |
| **AI 交易助手** | 用对话读取行情/账户/情报证据，生成交易机会与图表动作 |
| **AI 自动化** | 按唤醒条件在后台运行的 AI Profile，带审计与仓位复盘 |
| **系统化策略** | Python 策略回测、参数调优、实盘 Profile（免安装 Python） |
| **市场情报** | 新闻、情绪、资金流、Smart Money 与系统压力的时间序列证据 |

> [!TIP]
> 初次使用请全程在 **OKX 模拟盘（Demo）** 上验证。模拟盘与实盘使用独立凭据，所有下单、通知和风控流程完全一致。

> [!WARNING]
> Desic Terminal 不构成投资建议。永续合约、杠杆与自动化交易可能造成快速且显著的损失。

## 2. 安装

前往 [GitHub Releases](https://github.com/xiazhi88/Desic-Terminal/releases) 下载与系统匹配的安装包：

| 平台 | 安装包 |
| --- | --- |
| Windows x64 | `Desic-Terminal_Windows-x64-setup.exe` |
| macOS Apple Silicon（M1+） | `Desic-Terminal_macOS-arm64.dmg` |
| macOS Intel | `Desic-Terminal_macOS-x64.dmg` |

> [!IMPORTANT]
> 当前安装包未使用 Apple Developer ID / Windows Authenticode 签名。macOS 首次启动时把应用拖入"应用程序"，右键选择"打开"；Windows 的 SmartScreen 提示请确认下载来源后选择继续。

**系统要求**

- Windows 10+ 或 macOS 12+
- 能访问 OKX 与所选 AI 供应商的网络环境
- **无需安装 Python**：系统化策略研究所需的 Python 运行时已随安装包内置

## 3. 首次启动

1. 启动后主窗口默认进入**交易工作站**：顶部是标题栏与自选列表，中间是 K 线，右侧是盘口与下单面板。
2. 左侧导航栏切换工作域：交易、机会、AI 自动化、系统化研究、市场情报、数据。
3. 右上角通知中心收集所有应用内通知；可以在设置中把通知转发到飞书机器人。

> [!NOTE]
> 桌面端启动时数据库初始化与后台恢复在独立任务中执行。首次打开"系统化研究"时会自动准备内置 Python 环境（进度显示在工作区标题栏底部），完成后回测与 Profile 立即可用。

---

## 4. 配置 OKX 账户

**设置 → 账户** 中新增账户：

1. 在 OKX 创建 **API Key**，并只授予交易相关权限。
2. 填写 Key / Secret / Passphrase，选择环境（`demo` 模拟盘或 `live` 实盘）。
3. 保存后桌面端会通过 Private WebSocket 建立独立连接，并同步历史成交与订单。

| 建议 | 说明 |
| --- | --- |
| 先配模拟盘 | 数量单位、保证金模式、止损与通知流程先在模拟盘跑通 |
| 不放提现权限 | API Key 不应包含提现权限 |
| 独立凭据 | 模拟盘与实盘使用各自独立的 Key |

> [!WARNING]
> 任何 AI 或自动化执行的实盘操作都需要显式确认。请确认你理解每个账户的权限范围。

## 5. 熟悉交易工作站

交易工作站的所有面板共享同一个交易对与账户上下文：

- **自选列表**：左侧切换交易对，支持拖拽排序。
- **盘口 / 深度**：右侧实时档位与深度图。
- **逐笔成交**：最近成交流。
- **下单面板**：限价、市价、计划委托；可附加止盈止损、OCO。
- **持仓与挂单**：下方标签页管理仓位、改单、撤单、平仓。

所有数量按 OKX 合约"张"提交，同时展示币数量、名义价值、预计保证金、费用与止损风险，避免张数与币数混淆。

**图表基础操作**

| 操作 | 方式 |
| --- | --- |
| 切换周期 | 图表工具栏（1m ~ 1M） |
| 添加指标 | 指标按钮 → 选择指标与参数，可加多个实例 |
| 图层开关 | 图层按钮 → 指标 / 价格线 / 绘图 / 分析 / 真实成交 / 测距 |
| 独立窗口 | 图表窗口按钮 → 单图/双图/三图/四图布局，每个窗格独立交易对与周期 |
| 快速交易 | 右键图表或拖拽价格线直接生成交易意图 |

## 6. 完成第一笔交易

以一笔**模拟盘限价单**为例：

1. 顶部账户切换器选择模拟盘账户。
2. 在下单面板选择 `限价`、方向（做多/做空）、价格与数量，可附带止盈止损。
3. 预览确认弹窗会展示合约张数、预计保证金与费用——核对后提交。
4. 挂单出现在"委托"标签；成交后进入"持仓"，图表上出现**持仓线、开仓价格线与止盈止损线**（可拖拽调整）。
5. 平仓可以点击持仓行，或在图表持仓线上拖拽到目标价格快速平仓。

> [!NOTE]
> 每一笔交易都会经过数量规范化、Rust 风控预检、幂等预留与审计记录。提交后若网络超时，桌面端会用稳定执行键与 OKX 对账，不会盲目重试。

## 7. 配置 AI 助手

**设置 → AI** 配置模型服务：

1. 选择一个供应商：OpenAI、Anthropic、Gemini、Grok、DeepSeek、通义千问、KIMI、豆包、MiniMax、智谱或任意兼容接口。
2. 填写 API Key 与模型名，保存并完成连通性测试。
3. 也可以配置本机官方 **Codex CLI** 或 **Claude Code** 通道——请求仍服从终端内的工具权限。

> [!TIP]
> 不同供应商的模型能力、上下文长度与费用差异较大。可以先从性价比高的模型开始，在会话中按需切换。

## 8. 用 AI 分析市场

打开右侧 **AI 交易助手**：

1. 提问，例如：

   ```text
   读取 BTC-USDT-SWAP 的实时价格、盘口、1 小时 K 线、资金费率与持仓量，
   给出简洁分析并标注数据时间。
   ```

2. 助手通过**白名单工具**读取实时行情、账户、订单、历史、新闻与 Smart Money 证据，流式展示推理、工具调用与耗时。
3. 工具结果会标注**数据时间、来源与新鲜度**，模型能区分事实、推断与数据缺口。

**权限模式**（在会话/配置中选择）：

| 模式 | 读市场与账户 | 交易机会 | 外部交易副作用 |
| --- | :---: | :---: | --- |
| `advisor` | 是 | 否 | 禁止 |
| `copilot` | 是 | 创建/修改/复用 | 必须由用户审批 |
| `limited_auto` | 是 | 冻结候选提交 | 仅限 Profile 授权范围 |

> [!IMPORTANT]
> 权限是硬边界，不是提示词。模型无法通过输出文本提升自己的权限。

## 9. 自定义图表指标

指标中心内置 MA、EMA、VWAP、Bollinger、Supertrend、Ichimoku、MACD、RSI、KDJ、ATR、ADX、Stochastic、CCI、ROC、Williams %R、MFI、OBV 等常用指标。

自定义指标使用**安全的 JSON DSL**（不执行 JavaScript、不开放文件与网络）：

1. 指标中心 → 新建自定义指标。
2. 在 CodeMirror 编辑器中编写表达式，或使用**指标 AI 助手**多轮讨论思路——只有明确要求创建/更新时才生成 DSL。
3. 保存后经过 Schema 校验与版本管理，进入指标库，可在任意图表加载。

## 10. 市场情报

情报面板是一组**可被人工与 AI 工具共同引用的时间序列证据**：

- **新闻与事件**：列表、全文、聚类、重要性与多窗口市场反应
- **情绪**：币种情绪快照、趋势、热度与多空排行
- **经济日历**：周历/月历、地区、重要性、前值/预测/公布值
- **资金结构**：价格与 OI 组合、主动买卖流、普通与精英账户多空结构
- **Smart Money**：交易员绩效、持仓、历史订单、聚合信号与分歧
- **衍生品状态**：资金费率、基差、强平样本、保险基金、价格限制与 ADL

每个视图都披露数据时间与覆盖率；缺失或过期的数据会被明确标记，不会用旧快照冒充当前状态。
